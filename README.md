# 会务通 MeetingFlow

从报名到证书的一站式会务系统。面向高校、学会与机构的会议全流程管理：活动发布、在线报名、资格审核、电子票与签到码、现场签到、证书签发与在线验真。

## 功能

**参会者端**

- 活动日历与筛选、活动详情（议程 / 嘉宾 / 票种）
- 在线报名表（票种选择、手机号与邮箱校验、需审核的活动进入待审核）
- 电子票：报名号、二维码、加入日历（.ics）、取消报名
- 我的报名：本机记录与报名号 / 手机号 / 邮箱 / 姓名查询
- 证书下载（PNG / 打印）与证书验真

**主办方后台**

- 工作台：报名与签到对比、报名状态构成、待审核与待签发提醒
- 活动管理：新建活动、票种与审核规则、开放 / 停止报名
- 报名名单：搜索、状态筛选、批量通过、单条审核与签到、补发证书
- 现场签到台：报名号 / 手机号 / 姓名核验，防重复签到
- 证书中心：三套证书版式、批量签发、作废、下载与验真

## 技术栈

React 19 · TypeScript · Vite · Tailwind CSS 3 · shadcn/ui · Radix UI · Recharts · React Router 7 · Sonner

证书由 Canvas 实时绘制（1600 × 1131），可导出 PNG 或直接打印为 PDF。演示数据持久化在浏览器 `localStorage`，后台侧栏可一键重置。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 生产构建
```

## 路由

| 路径 | 说明 |
| --- | --- |
| `/` | 活动日历 |
| `/events/:slug` | 活动详情 |
| `/events/:slug/register` | 报名表单 |
| `/ticket/:code` | 电子票与签到码 |
| `/my` | 我的报名 |
| `/verify/:certNo` | 证书验真 |
| `/admin` | 主办方工作台 |
| `/admin/events` | 活动管理 |
| `/admin/events/:id` | 单场活动的报名 / 签到 / 证书 |
| `/admin/certificates` | 证书中心 |
| `/admin/checkin` | 现场签到台 |

## 说明

演示环境预置 4 场活动、40 余条报名与 7 份已签发证书（编号 `MF-2026-0001` 起），所有数据仅保存在本机浏览器，不会上传服务器。
